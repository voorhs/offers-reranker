# Реранкер офферов

Реранкер офферов служит цели отсортировать поисковую выдачу в каталоге товаров. Сейчас есть сервис, выкаченный в продакшн, в нем в данный момент задачу фильтрации и сортировки выполняет LLM. В данном проекте я обучаю BERT-like кросс-энкодер, чтобы заменить сложный и тяжелый шаг вызова LLM.

## Данные

Я [выгрузил](./etl) входы и выходы LLM из нашей системы инструментирования ([Logfire](https://logfire.pydantic.dev/docs/)) и сконвертировал в формат, пригодный для обучения модели ранжирования. Каждый семпл это:
- текстовый поисковый запрос
- список пар "оффер - золотой скор релевантости"

## Целевые метрики

- NDCG@3 > 0.6
- Среднее время отклика сервиса ≤ 0.8 с
